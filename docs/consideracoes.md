## Considerações Finais

Conseguimos aplicar toda a teoria pesada de análise e desenvolvimento de sistemas em um produto prático, que resolve um problema bem real do mercado de informática.

Apostar na estrutura do VitePress integrada com o GitHub e Vercel abriu nossa cabeça para o conceito de Doc-as-Code (documentação tratada como código), tornando o processo de atualização muito mais ágil e profissional. O projeto ficou maduro, bem estruturado e com uma base sólida para futuras melhorias, como adicionar uma Inteligência Artificial para sugerir peças focadas no orçamento do cliente!

Como adotamos a mentalidade de MVP (Minimum Viable Product), tivemos que focar no "coração" do sistema para garantir a entrega dentro do prazo da disciplina de Desenvolvimento de Sistemas 1. Se fôssemos continuar o desenvolvimento da TechForge para além do ambiente acadêmico, o nosso backlog de melhorias contaria com três grandes recursos

Em resumo, a TechForge nasceu como um trabalho avaliativo, mas se provou uma solução comercialmente viável e tecnicamente rica. Conseguimos criar um sistema especialista completo, que protege o bolso do cliente leigo e agiliza a vida do técnico de informática. Estamos com o projeto publicado, a documentação 100% estruturada no VitePress e prontos para a banca de apresentação na Vercel
